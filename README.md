# Лабораторная работа №8 — CRUD в WinForms

Приложение на C# (Windows Forms) для работы с базой данных студентов
StudentDB через ADO.NET. Реализует полный цикл CRUD-операций:
создание, чтение, обновление и удаление записей.

---

## Цель работы

Научиться реализовывать полный цикл работы с данными в WinForms:
- добавление новой записи (INSERT);
- редактирование существующей (UPDATE);
- удаление записи (DELETE);
- чтение данных (SELECT);
- использовать параметризованные SQL-запросы и обрабатывать ошибки БД.

---

## Функционал

### Базовый CRUD
- Create — добавление нового студента через форму.
- Read — загрузка всех студентов в DataGridView при запуске.
- Update — редактирование выбранного студента.
- Delete — удаление с подтверждением (MessageBox Да/Нет).

### Дополнительно (Шаг 7 задания)
- Проверка дубликата — перед добавлением выполняется
  SELECT COUNT(*) FROM Students WHERE FullName = @name.
  Если студент с таким ФИО уже есть — добавление отменяется.
- Экспорт в CSV — сохранение таблицы в файл через SaveFileDialog
  (кодировка UTF-8, разделитель ;).
- Счётчик студентов — в labelStatus отображается общее число
  записей после каждой операции.
- Кнопка «Отмена» — сбрасывает поля и перезагружает таблицу из БД.

### Валидация
- ФИО и группа не могут быть пустыми.
- Возраст ограничен диапазоном 15–100 (NumericUpDown).
- Средний балл — 0–5 с шагом 0.1 (NumericUpDown).
- Проверки дублируются ограничениями CHECK в самой БД.

## Структура БД

База данных: StudentDB, таблица Students.

| Столбец | Тип | Ограничения |
|---|---|---|
| Id | INT | PRIMARY KEY, IDENTITY(1,1) |
| FullName | NVARCHAR(100) | NOT NULL |
| Age | INT | NOT NULL, CHECK (15..100) |
| GroupName | NVARCHAR(20) | NOT NULL |
| AverageGrade | FLOAT | CHECK (0..5) |

SQL-скрипт создания БД и таблицы — в файле database.sql
(из лабораторной работы №5).

## Интерфейс

Форма разделена на две части:

Верхняя — таблица dataGridViewStudents со списком студентов
(только для чтения, выбор строки целиком).

Нижняя — панель редактирования:

| Элемент | Назначение |
|---|---|
| textBoxName | ФИО |
| numericAge | Возраст (15–100) |
| textBoxGroup | Группа |
| numericGrade | Средний балл (0–5, шаг 0.1) |
| buttonAdd | Добавить запись |
| buttonUpdate | Сохранить изменения |
| buttonDelete | Удалить запись (с подтверждением) |
| buttonClear | Очистить поля |
| buttonExport | Экспорт таблицы в CSV |
| buttonCancel | Отменить изменения и перезагрузить |
| labelStatus | Статус + счётчик студентов |

При выборе строки в таблице её данные автоматически подставляются
в поля редактирования.
